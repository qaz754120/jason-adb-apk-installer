# 程式更新說明

作者：**Jason1993余**  
分類：手機 → 安卓 → 安裝程式

## 使用者會看到什麼

從 **v1.1.0** 起，程式開啟時會向本專案的固定更新網址檢查正式版本。一般更新可選擇立即更新，或延後一週／一個月再提醒。開始下載後會驗證更新資料與補丁；驗證成功才交給獨立更新程式更換檔案並重新開啟主程式。

舊的 **v1.0.1 沒有更新檢查功能**，必須先手動升級至 v1.1.0 或後續含更新功能的版本一次。發布新版本不會讓既有 v1.0.1 自動長出更新功能。

更新的是電腦上的小金 ADB 安裝助手及補丁內明確允許的自有檔案。使用者選擇的 APK、手機內容、ADB 私鑰及安裝紀錄不會傳給更新服務；現有 `APK` 與 `platform-tools` 資料夾不由此更新機制覆寫。公開補丁不包含 Google 的 ADB 執行檔或使用者 APK。

## 提醒與強制更新規則

畫面版號用來辨認功能版本；強制更新使用每次正式發布增加一次的整數 `releaseSequence`。例如 v1.0.1 的序號是 1，v1.1.0 的序號是 2。後續正式發布依序為 3、4、5，不能跳號來增加落後差距。

| 狀況 | 行為 |
| --- | --- |
| 已是目前正式版本 | 正常使用。 |
| 落後 1 或 2 次正式發布 | 提醒更新，可選一週或一個月後再提醒。 |
| 落後至少 3 次正式發布 | 必須完成更新才能使用 APK 安裝功能，不能用延後提醒解除限制。 |
| 低於作者在已簽署資料中設定的最低支援序號 | 必須更新；此規則可用於重大相容性或安全修正。 |
| 檢查失敗，且沒有已驗證的強制更新紀錄 | 顯示檢查狀態，保留離線使用能力。 |
| 已經收到並驗證強制更新要求，之後離線 | 仍保留該要求，可重新連線更新。 |

強制條件為：`最新 releaseSequence − 本機 releaseSequence >= 3`，或本機序號小於 `minimumSupportedSequence`。比較的是正式發布次數，不是把 `1.9` 和 `2.0` 當小數相減。以目前序號 2 為例，最新版序號 4 時可延後；最新版序號 5 時必須更新。

「一週後」為七天；「一個月後」為下一個曆月的相應日期，日期不存在時採該月最後一天。提醒時間到了，會在之後開啟程式／進行更新檢查時提醒，不會在程式未執行時跳出系統通知。

延後提醒只影響一般更新通知。程式仍會在啟動時檢查版本，避免延後期間已超過強制門檻卻被略過。更新檢查本身有逾時限制，不會一直等待網路。正在執行 ADB 安裝時，須先完成或正常停止該次作業，才可替換主程式。

## 下載與驗證

1. 透過 HTTPS 讀取固定的官方更新資料，不接受任意下載網站或任意命令。
2. 用程式內建公鑰驗證更新資料的 RSA／SHA-256 簽章。
3. 核對發布序號及最低支援政策，拒絕回到比已知資料更舊的更新。
4. 下載指定補丁，檢查長度與 SHA-256，然後只處理允許的檔案路徑。
5. 主程式關閉後，獨立更新程式再次檢查資料，備份將被替換的檔案，再套用補丁。

補丁採用完整檔案替換，並非只存二進位差異的增量檔。每一版應包含升級所需的全部自有執行檔與必要說明，讓使用者可以跨過中間版本直接升級。更新後保留的備份及作業紀錄用於失敗時復原；不要在更新尚未完成時自行刪除。

補丁不覆寫使用者資料夾中既有的 `src` 原始碼或 `Build.cmd`。若需要自行建置，請重新取得 GitHub 上對應版本的完整原始碼；不要用留在舊資料夾的原始碼重新編譯並覆蓋剛更新的執行檔。

補丁驗證失敗、下載中斷、權限不足或檔案遭其他程式占用時，應先處理原因，再重新嘗試。不要關閉 Windows 安全防護來略過驗證。若原本已達強制更新條件，下載失敗不會讓該條件自動解除。

## 離線與商業用途的界線

完全離線、且從未取得新版本資訊的程式，無法知道遠端已有幾個新版本。本機的版本限制也不是防破解或付費驗證系統；能修改程式或刪改本機資料的人，可能繞過本機限制。

這次功能負責版本通知與補丁更新，不包含付款、帳號登入、授權碼、訂閱到期、遠端停權或付費版權限。商業授權規劃請見 [商業販售規劃](COMMERCIAL-ROADMAP.md)，目前使用範圍仍以根目錄 [LICENSE](../LICENSE) 為準。

## 連線與隱私

更新連線只取得版本資料及補丁，不上傳 APK、手機序號、安裝紀錄或 Windows 使用者路徑。HTTPS 服務及其網路供應商仍會收到一般連線資料，例如來源 IP、請求時間及所請求網址；這不等於完全沒有網路中繼資料。

提醒偏好與已驗證更新資料留在目前 Windows 使用者的本機資料目錄。這些是程式狀態，不應放進公開補丁或 GitHub 原始碼。
