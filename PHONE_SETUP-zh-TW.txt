手機連線設定教學｜四品牌整合版

在程式內按「手機設定教學」，可分頁閱讀小米、Sony、Google、Samsung 及共同問題。
這次需要開發人員選項與 USB 偵錯，不需要 Root 或裝置管理員權限。

小米 Xiaomi／REDMI／POCO：HyperOS、MIUI

這次要開的是「開發人員選項」及「USB 偵錯」，不需要 Root、裝置管理員或 OEM 解鎖。

1. 開啟「設定 → 關於手機」。有些版本顯示「我的裝置／我的設備」。找到「OS 版本／系統版本」或「MIUI 版本」；若沒有，先進入「詳細資訊與規格／所有規格」。
2. 連點 OS／MIUI 版本約 7 次，直到提示已成為開發人員。若要求螢幕鎖定密碼，請本人輸入。不要改點 Android 版本。
3. 返回「設定 → 更多設定／其他設定 → 開發人員選項」，保持總開關開啟。
4. 開啟「USB 偵錯」，部分介面稱「USB 調試」。閱讀並確認手機提示；有倒數時等候完成。
5. 接上可傳資料的 USB 線，解鎖手機，在 RSA 授權視窗按「允許」。回工具重新整理，裝置顯示 device 後即可安裝。

若安裝被拒絕：先查看手機是否要求允許此 APK 透過 USB 安裝。若畫面另有「USB 安裝」且提示需啟用，依該手機指示處理。部分版本另有「設定 → 應用程式 → 權限 → 透過 USB 安裝」入口。

選項會因機型、地區與版本而異；沒有該項目就跳過。本教學不把登入小米帳號、插入 SIM 或開啟「USB 偵錯（安全性設定）」當成全部機型的必要條件。找不到手機時，請看「共同步驟／常見問題」頁籤。

如果「開發人員選項」已經出現，就直接進入確認開關，不需再連點版本。沒有選到 APK 時也可以先完成連線；手機授權後回工具按「瀏覽 APK」，選好檔案再安裝。

Sony Xperia

開啟「開發人員選項」與「USB 偵錯」即可使用本工具；不需要 Root、解鎖開機載入器或刷機。

1. 在較新的 Xperia，開啟「設定 → 關於手機 → 版本號碼」。部分較舊版本的路徑為「設定 → 系統 → 關於手機 → 版本號碼」。
2. 連續點選「版本號碼」7 次，直到手機提示已啟用開發人員選項。若要求 PIN、圖形或密碼，請在手機上本人輸入。
3. 返回「設定 → 系統 → 開發人員選項」。若看不到，先展開「進階」；更舊的系統可能直接在設定主頁顯示開發人員選項。
4. 保持開發人員選項總開關開啟，找到「USB 偵錯」並開啟，確認手機的說明視窗。
5. 使用可傳資料的 USB 線連接電腦，保持手機解鎖。出現「允許 USB 偵錯？」及 RSA 指紋時，確認此次連接的電腦後按「允許」。
6. 回小工具重新整理裝置，按「瀏覽 APK」選檔；裝置顯示 device 後開始安裝。

如果電腦只能充電或仍找不到手機，換資料線或 USB 孔後重試；可從手機 USB 通知選「檔案傳輸」。若 Windows 缺少 ADB 驅動，請依 Xperia 機型及 Sony 官方說明處理。不同 Android 版本的位置會不同，可在設定搜尋「開發人員選項」。不要為了安裝 APK 執行 Xperia 軟體修復或還原原廠設定。

若工具顯示未授權，代表已找到手機但尚未允許這台電腦；請先看手機畫面。開發人員選項已存在時可直接使用，不用關閉再重新開啟。裝好後在手機開啟應用程式確認。

Google Pixel

這裡使用手機的「開發人員選項 → USB 偵錯」，不需要 Root、裝置管理員或解鎖開機載入器。

1. 開啟手機「設定 → 關於手機」，捲動到底部找到「版本號碼」（Build number）。
2. 連點版本號碼 7 次，直到手機提示已成為開發人員。若要求手機的 PIN、圖形或密碼，請本人輸入；已啟用時可直接進行下一步。
3. 返回「設定 → 系統 → 開發人員選項」。部分較舊 Android 版本需先展開「進階」。
4. 保持「使用開發人員選項」總開關開啟，找到「USB 偵錯」並開啟，再確認手機提示。
5. 使用可傳資料的 USB 線連接電腦，保持手機解鎖。出現「允許 USB 偵錯？」與 RSA 指紋時，確認是這次使用的電腦後按「允許」。
6. 回到小工具重新整理裝置；顯示 device 表示 ADB 已可使用。按「瀏覽 APK」選取檔案，再開始安裝。

若顯示 unauthorized，請查看手機授權視窗，而不是重複按安裝。沒有提示時先重新插線，保持手機解鎖。完全沒有裝置時可更換資料線與 USB 孔；Windows 若缺驅動，可依 Android 官方指引使用 Google USB Driver，安裝權限以電腦規定為準。

本工具使用 USB 偵錯，不需啟用無線偵錯、OEM 解鎖或「等待偵錯工具」。路徑隨系統版本可能略有差異；其他品牌可參考共同頁籤的一般 Android 步驟。

若先前已授權這台電腦，本次可能不再彈出確認框。只要工具的裝置狀態顯示可用即可繼續；手機列表空白與未授權是兩種情況，請分別依共同頁籤的對應步驟處理。

官方來源：
https://developer.android.com/studio/debug/dev-options
https://developer.android.com/codelabs/basic-android-kotlin-compose-connect-device


Samsung Galaxy（三星／One UI）

這次需要開發人員選項與 USB 偵錯，不需要 Root、裝置管理員或 OEM 解鎖。

1. 開啟「設定 → 關於手機 → 軟體資訊 → 版本號碼」（Build number）。
2. 連點版本號碼 7 次，直到提示已開啟開發人員模式。若要求手機的 PIN、圖形或密碼，請本人輸入。
3. 回到設定主頁，捲動到最下方，開啟「開發人員選項」。部分舊版可能在「一般」內。
4. 保持總開關開啟，開啟「USB 偵錯」，並確認手機上的說明。
5. 接上可傳資料的 USB 線，解鎖手機；出現「允許 USB 偵錯？」及 RSA 指紋時，確認是這次使用的電腦後按「允許」。
6. 回小工具重新整理裝置。裝置顯示 device 後，按「瀏覽 APK」選檔安裝。

若 USB 指令或 APK 安裝被封鎖，可查看「設定 → 安全性與隱私權 → 自動封鎖程式」。Samsung 官方說明此功能可能封鎖 USB 指令與非商店安裝；只有確認 APK 可信、裝置由你管理並允許變更時，才依官方指引暫時調整，完成後恢復原設定。工具不會替你關閉它。

若 USB 偵錯呈灰色、顯示管理員限制，或屬於受管理手機，請由有權管理的人員處理。Windows 找不到裝置時，檢查資料線及 Samsung Android USB Driver；驅動安裝可能需要管理員權限。

首次授權完成後，下次連接同一台電腦可能不再顯示確認框。若清單同時有其他手機或模擬器，請確認選對目標，避免把 APK 安裝到另一個裝置；不確定時先拔除其他裝置再重新整理。

共同步驟／常見問題

本工具要用的是「開發人員選項 → USB 偵錯」。手機尚未授權前，電腦無法替你打開手機端開關或接受授權。

【USB 授權與安裝】
1. 先完成所選品牌的手機設定，使用可傳資料的 USB 線連接並解鎖手機。
2. 手機出現「允許 USB 偵錯？」與 RSA 指紋時，確認此次連接的電腦後按「允許」。常用自用電腦可依需求勾選「一律允許」。
3. 回工具重新整理裝置。device 表示可用；多部裝置時請明確選擇要安裝的手機。
4. 按「瀏覽 APK」從電腦選檔，或拖入 APK，再開始安裝。一鍵模式會在只有一個 APK 與一部可用手機時自動開始。留意手機是否另有安裝確認。

【連線問題】
找不到裝置：確認 USB 偵錯、手機解鎖、資料線及 USB 孔；可改選手機 USB 通知內的「檔案傳輸」後重試。Windows 缺少 ADB 驅動時使用品牌官方驅動，安裝權限依電腦規定。
unauthorized／未授權：先在手機接受 RSA 授權，再重新整理；沒提示時拔插 USB 再試。
offline／離線：等手機開機完成，重新插線並整理裝置清單。

【未列出的其他品牌】
通常先進「設定 → 關於手機 → 版本號碼」，部分機型在「軟體資訊」內；連點 7 次後，在「系統／進階／設定主頁」找開發人員選項，開啟 USB 偵錯。可用設定搜尋欄協助尋找，實際位置依品牌而異。

取消或逾時不等於撤回手機端安裝；先查看手機 App 清單及紀錄，再決定是否重試。受管理裝置的限制，需由有權管理的人員處理。

https://developer.android.com/tools/adb
