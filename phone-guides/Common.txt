共同步驟／常見問題

本工具要用的是「開發人員選項 → USB 偵錯」。手機尚未授權前，電腦無法替你打開手機端開關或接受授權。

【USB 授權與安裝】
1. 先完成所選品牌的手機設定，使用可傳資料的 USB 線連接並解鎖手機。
2. 手機出現「允許 USB 偵錯？」與 RSA 指紋時，確認此次連接的電腦後按「允許」。常用自用電腦可依需求勾選「一律允許」。
3. 回工具重新整理裝置。device 表示可用；多部裝置時請明確選擇要安裝的手機。
4. 按「瀏覽 APK」從電腦選檔，或拖入 APK，再開始安裝。一鍵模式會在只有一個 APK 與一部可用手機時自動開始。留意手機是否另有安裝確認。

【連線問題】
找不到裝置：確認 USB 偵錯、手機解鎖、資料線及 USB 孔；可改選手機 USB 通知內的「檔案傳輸」後重試。Windows 缺少 ADB 驅動時使用品牌官方驅動，安裝權限依電腦規定。
unauthorized／未授權：先在手機接受 RSA 授權，再重新整理；沒提示時拔插 USB 再試。
offline／離線：等手機開機完成，重新插線並整理裝置清單。

【未列出的其他品牌】
通常先進「設定 → 關於手機 → 版本號碼」，部分機型在「軟體資訊」內；連點 7 次後，在「系統／進階／設定主頁」找開發人員選項，開啟 USB 偵錯。可用設定搜尋欄協助尋找，實際位置依品牌而異。

取消或逾時不等於撤回手機端安裝；先查看手機 App 清單及紀錄，再決定是否重試。受管理裝置的限制，需由有權管理的人員處理。
